# 🎨 Guía de Estilo (Solutech)

Sistema de diseño visual para mantener la estética Premium y "Dark" de Solutech.

## 🌈 Paleta de Colores
- **Naranja Solutech (`--o`)**: `#e8621a` (Acción, acentos, vitalidad).
- **Fondo Primario (`--bg`)**: `#07070b` (Deep Dark).
- **Superficies (`--s1`, `--s2`)**: `#0e0e14`, `#13131a` (Para tarjetas y secciones).
- **Texto Primario (`--t`)**: `#f0ede8` (Off-white para evitar fatiga visual).

## 🔤 Tipografía
- **Títulos (Serif)**: `Instrument Serif`. Usar con itálica para dar énfasis "Boutique".
- **Cuerpo (Sans)**: `Geist`. Moderna, técnica y legible.
- **Datos/Código (Mono)**: `Geist Mono`. Para etiquetas, estados y fechas.

## 💠 Componentes Visuales
- **Gradients**: Usar sutiles resplandores radiales (`radial-gradient`) en fondos oscuros.
- **Bordes**: Siempre sutiles (`rgba(255,255,255,0.07)`).
- **Animaciones**: Usar el `IntersectionObserver` definido para entradas suaves (`reveal in`).

## 📸 Imágenes
- **Formato**: Preferiblemente WebP optimizado (< 300kb).
- **Estética**: Imágenes con tonos oscuros, contrastes técnicos y alta calidad.
